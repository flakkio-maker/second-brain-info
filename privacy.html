Informativa sulla privacy - Second Brain

Ultimo aggiornamento: 12 novembre 2026.

Cos'è

Second Brain è un'applicazione personale per uso esclusivo del suo proprietario. Non è offerta ad altri utenti.

Quali dati usa

Con il consenso del proprietario, legge in sola lettura (permesso gmail.readonly) i messaggi delle caselle Gmail del proprietario, per costruire un indice di ricerca personale.

Dove restano i dati

Tutti i dati letti e l'indice di ricerca restano su un computer del proprietario. Non sono inviati a server esterni, non sono condivisi, venduti o ceduti a terzi, e non sono usati per pubblicità o per addestrare modelli di intelligenza artificiale. Gli embedding sono calcolati localmente.

Uso dei dati Google

L'uso e il trasferimento di informazioni ricevute dalle API di Google rispettano la Google API Services User Data Policy, inclusi i requisiti di Uso limitato.

Revoca e cancellazione

Il proprietario può revocare l'accesso in qualsiasi momento da myaccount.google.com/permissions e cancellare l'indice locale eliminando il relativo file.

Contatti

Per domande, aprire una segnalazione (issue) nel repository GitHub di questa pagina.

English summary

Second Brain is a private single-user tool. It reads the owner's own Gmail read-only to build a personal search index stored only on the owner's computer. Data is not shared, sold, transferred to third parties, used for advertising or used to train AI models. Use of Google API data complies with the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions.
